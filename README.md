# Дом-музей И. С. Тургенева — стабилизированная версия

В этой сборке сохранена прежняя визуальная концепция и основные разделы сайта, но закреплены навигация, отображение ролей предпросмотра и модель административного доступа.

## Файлы для публикации
- `index.html`
- `app.js`
- `styles.css`

`config.js` специально не включён: сохраните свой текущий файл с Supabase URL и Publishable/anon key. Не публикуйте Secret/service_role key.

## Быстрый порядок обновления
1. Сделайте резервную копию файлов репозитория и базы данных.
2. Замените три файла сайта.
3. Если миграция `20261119_admin_only_and_role_previews.sql` уже выполнялась, запустите только `20261120_admin_preview_helper_hardening.sql`.
4. Если предыдущая миграция ещё не выполнялась, сначала запустите `20261119_admin_only_and_role_previews.sql`, затем `20261120_admin_preview_helper_hardening.sql`.
5. Сохраните старую папку `.github/workflows`, `config.js` и остальные настройки публикации.
6. Commit & push и проверьте сайт по `QA_CHECKLIST_RU.md`.

Это стабилизационный этап, а не полная смена технологического стека. Полная миграция на React/TypeScript не выполнялась: текущий интерфейс и существующие сценарии сохранены, а навигация и отображение модулей изолированы без риска потерять уже накопленную функциональность.
