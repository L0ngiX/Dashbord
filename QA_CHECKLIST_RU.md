# Контрольный список проверки после публикации

## В обычном окне без входа
- [ ] Открывается только страница «О здании».
- [ ] В меню отсутствуют чертежи, эксплуатация и командные разделы.
- [ ] Нет переключателя тестовых профилей.
- [ ] Нельзя открыть закрытый раздел через прямое нажатие/URL.
- [ ] В Supabase anon не может читать таблицы участников, задач, чертежей и техсостояния.

## Администратор
- [ ] Вход выполняется по email и паролю.
- [ ] Аккаунт без `profiles.role='admin'` не допускается.
- [ ] После входа отображается переключатель предпросмотра.
- [ ] В режиме Visitor видна только публичная страница и отключено редактирование.
- [ ] В режиме Design видны публичная страница и чертежи, но не эксплуатационные и командные данные.
- [ ] В режиме Maintenance видны публичная страница и эксплуатация, но не чертежи и командные данные.
- [ ] В режиме Owner видны все страницы, но все элементы изменения отключены.
- [ ] В режиме Admin доступны все страницы и редактирование.
- [ ] После выхода остаётся только публичная страница.

## Навигация и вёрстка
- [ ] Между вкладками нет одновременного отображения двух страниц.
- [ ] Переход сопровождается плавным появлением активного раздела.
- [ ] Переключение вкладок не сбрасывает прокрутку внутренних списков.
- [ ] Ширина рабочей области не смещается из-за появления/исчезновения вертикальной полосы прокрутки.
- [ ] Проверены desktop, tablet и mobile ширины.
- [ ] Проверены светлая и тёмная темы.

## Сохранение
- [ ] Изменения в административном режиме сохраняются после обновления.
- [ ] В режиме предпросмотра изменение невозможно.
- [ ] При недоступной базе интерфейс показывает ошибку подключения и не сохраняет локально как будто данные опубликованы.
